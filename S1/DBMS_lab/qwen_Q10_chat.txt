### **11. SUB-QUERIES**

**1. Insert into deposit a new record (107,Sandeep,Ajne,2000,12032011). Display the customers' names whose branch is same as that of the branch of Sandeep.**
*Note: MySQL requires dates in `YYYY-MM-DD` format. "Sndeep" is corrected to "Sandeep".*
```sql
-- Insert the new record
INSERT INTO deposit VALUES (107, 'Sandeep', 'AJNE', 2000.00, '2011-03-12');

-- Display customers in the same branch as Sandeep
SELECT cname FROM deposit WHERE bname IN (SELECT bname FROM deposit WHERE cname = 'Sandeep');
```

**2. Give the number of customers who are depositors as well as borrowers.**
```sql
SELECT COUNT(DISTINCT cname) AS common_customers 
FROM deposit 
WHERE cname IN (SELECT cname FROM borrow);
```

**3. Delete the record from loans who have a deposit.**
*Note: The table name in your schema is `borrow`, not `loans`. The query below uses `borrow`.*
```sql
DELETE FROM borrow 
WHERE cname IN (SELECT cname FROM deposit);
```

### **12. VIEWS IN DBMS**

**1. Create a view for the table deposit with fields accno, cust name and branch name**
```sql
CREATE VIEW deposit_details AS
SELECT accno, cname, bname 
FROM deposit;
```

**2. Create a view that gives information about customer name, deposit amount and living city**
*Note: This requires joining the `deposit` and `customer` tables on the customer name.*
```sql
CREATE VIEW customer_deposit_city AS
SELECT d.cname, d.amt, c.lcity 
FROM deposit d
JOIN customer c ON d.cname = c.cname;
```

**3. Create a view to display the borrow details having loan no 206**
```sql
CREATE VIEW loan_206_details AS
SELECT * 
FROM borrow 
WHERE loan_no = 206;
```

**4. Drop a view**
```sql
-- Example: Dropping the first view created
DROP VIEW deposit_details; 
```
